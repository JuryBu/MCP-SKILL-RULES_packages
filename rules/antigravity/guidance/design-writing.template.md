# 设计与文书：面向实际读者与视觉品味制作（Antigravity 2.0）

制作或改写网页前端、3D 场景、海报、PPT、Word/PDF 报告、讲稿或正式说明前读取本专题（配合对应格式 Skill；截图与多模态规则见 `guidance/web-visual.md`）。

---

## 一、受众文体与参考素材库（先正后负铁律）

1. **按真实读者写**：正式报告、学术文书与对外说明清除闲聊口吻、内部阶段代号与裸编号，直说结论与事实，不堆免责套话或机械模板腔。
2. **参考素材库流程**：
   - 若本机配置了风格参考素材库（路径见 `personal-care.local.md`），创作视觉界面、海报、PPT、3D 或关键文风前，先读其 `README.md` 与 `总索引.md`，挑选相关**正面案例**并**完整精读案例说明**，把案例中的渲染预算与缓存优化一并吸收进首版；
   - **创作前铁律**：成稿完成前不读负面库与负面参考索引，防污染创作直觉；
   - **成稿后排雷**：初稿完成后对照对应负面案例排雷，踩雷即改并重验渲染；
   - 若本机配置了私有中文表达例库且可读，写关键长中文文案时只读对照 1～2 份样例校准语感（不修改该目录）。

## 二、样稿、审美、首版流畅度与 PPT 习惯

- **样稿先行与离席交付**：用户在场且新视觉方向未定时，先做少量代表样稿确认；用户已离席且给了完整目标与正例时，直接交付完整初稿并排雷，不停等。展示成品或候选图一律输出**原尺寸高清单图**（未经要求不拼缩略多宫格）；日常汇报小表能讲清就不耗时硬搓网页。原创配图积极并行委派 `image-generator`。
- **拒绝 AI Slop 模板味**：不为了工整强套三栏圆角卡片、万能渐变紫底、三字排比标题或「从 X 到 Y」套话；先定信息层级与视线动线，再定字体、配色与克制动效。
- **首版流畅度与内存/显存预算**：
  - 常规 UI：长列表虚拟滚动或分页、重资源懒加载、高频事件合入 `rAF`/防抖、动效走 `transform`/`opacity` 防布局抖动；卸载或切路由时用 `AbortController` 取消旧请求并清理定时器与监听。
  - Canvas / WebGL / 3D：首版锁定高分屏像素面积上限、离屏 FBO 与着色器循环上限（防 Windows ANGLE D3D11 冷编译黑屏）、非截图关 `preserveDrawingBuffer`，页面隐藏时挂起 `rAF` 与 `AudioContext`；不做粗暴分帧跳卡的假优化。
- **PPT 四项硬习惯**：① 页面文案不把三个「主语+动词+宾语」串成同构动作句；② 页面文案不用句号，并列用换行与留白呈现；③ 标题问句只用设问或反问；④ 正式大制作走「排版前查内容增删与推进顺序 + 完成后查正负例与零背景读者扫看」。

---

## 三、交付前真实读者复核

以挑剔的零背景读者与真实使用者视角通查：脱离聊天上下文能否一眼看懂？有没有晕字术语、字号过小、遮挡、过曝泛白或边缘黑边？连续交互是否顺滑且切后台后资源干净释放？末轮改动后必重截受影响视角，确保成品与截图版本一致。
