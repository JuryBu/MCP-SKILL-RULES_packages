# 工程工作流：共识、隔离、排期、独立双审与防断恢复（Antigravity 2.0）

本专题遵循全局 `GEMINI.md`「专题阅读入口」：长工程（预估 `>10 分钟`、改 `>=3` 份文件、开发产品/服务/脚本、性能调优、跨阶段、双端配对/巡查、改线上配置或排子代理）开工、接手或恢复前通读；**经历 `<CONTEXT_SUMMARY>` 压缩或 `/compact` 后继续长工程、配对或半小时巡查时，首轮必补读本文件核回原总目标与必跑审查台账**（中小脚本至少跑 1.4 与 4.5 性能/回收闭环）。

## 一、开工共识、边界核实与物理隔离铁律

1. **先查再定案与双端跑腿整合（讨论不改码）**：从 `交流近况.md`、记忆与历史核原始意图、交付、验收、作息及边界；**配对讨论期用户找哪端，该端必主动同步新讯找搭档碰撞、带回异议与待问同轮整合答复，禁装哑巴或让用户转问「另一边怎么看」**，一次定死交付/先后/真假依赖/失联恢复与边界。多文件排查或疑点并发多路互不重叠 **`gemini-4-hydrogen-xhigh` 先遣**（不压人数）取精确行号与事实护主线，区分事实、推测与假设。
2. **线上服务隔离与拆依推进（禁转嫁成本）**：改运行服务/代理/网关内核、守护进程、全局配置或持久数据，**必先于 `%TEMP%` 独立副本与端口完成隔离验证**，备 SHA256 清单、独立回退脚本及不依赖升级对象的独立恢复入口；拆清「开窗实测/本批切换/后批准备」真依赖，趁离席按最小可回退单元连推（见 `maintenance-upgrades.md`），**禁攒大包全切，除人工操作/补权限/极端不可逆破坏外禁借「怕弹窗/有风险」停工让用户硬等**。
3. **目录与多端/并发防撞约定**：计划默认存 `plans/`（`index.md` + `Plan_x/` + `Task.md` 显式登记双审轮次、未闭环采纳项与下一触发点，末尾设『待复核/小本本』）；已有他端 `plans/` 时建 `plans_agy/`（及 `交流近况_agy.md`；公共根优先落 `<子目录>/plans_agy/` 或 `plans_agy/<主题>/` 防覆盖，获准协同改他端注明 `Antigravity 修改`）。长产出超 `1 万字` 拆模块或增量写；已完成 Stage 压一行摘要入 `memory-store`，每阶段走 `stage_guard(start -> 落盘产物与证据 -> check)`。
4. **交付物首版性能、内存与进程生命周期预算（禁堆完功能等催二轮优化）**：
   - **首版架构同步纳入四项指标**：前端、产品、服务或脚本定方案与写首版须按真实数据量同步设计：① **冷启动与首屏**：控初始化/编译耗时与首屏体积，禁全量同步阻塞；② **热路径复杂度与异步**：消除渲染/列表/事件/I/O 中的 `O(N^2)` 嵌套重算、主线程长阻塞、N+1 查询与高频 GC 抖动（拆流式增量、分页缓存或 Worker/后台队列）；③ **内存与显存封顶**：缓存、队列、DOM 池、离屏纹理/张量设容量上限与淘汰回收，防驻留内存单调增长；④ **进程与句柄确定性回收**：子进程树、线程、连接、文件锁、WebSocket、定时器、`rAF`、`AudioContext`/`WebGL` 在卸载、切后台、结束及异常中断（`try/finally`、信号、`AbortController`）时干净休眠或销毁，**禁留僵尸进程、孤儿句柄或后台空转吃满 CPU/GPU**。
   - **同化参考优化机制**：研读参考案例必同步提取容量封顶、预计算缓存与降级机制入方案，聚焦架构与复杂度上限，不搞冷路径微观炫技。

## 二、真实时钟排期与关键路径压缩

预估超 10m 或多线并行，记开始/预算/缓冲/复核点。**单端主攻与真·完全并行三铁律**：未配对或对端停机转单端施工，**当轮停离线原 `*/30` 查岗**（转单干 `*/8` 防断），**禁沿用轻巡查或单人手敲**，建本端 `plans/`（他端只读继承，于 `plans_agy/` 或 `.gemini/workstate/` 独立建档禁覆写他端）与双审台账跑满四步——① 多路 `Hydrogen XHigh` 摸底；② **实现与测试凡 `>=2` 独立模块/脚本/测试，首选同区独立文件边界拆多路 `Neon XHigh`（纯编码用 `swarm`；需 MCP `sandbox` 单测用独立路径 `invoke_subagent(TypeName="self", Model="inherit")`；共享仓禁 `workspace:"share"`，非共享仓 `share` 必合回验再 `kill`；复杂核心升 `Carbon High`）并行**（加多路 `image-generator` 配图）；③ 排期/关键阶段/收尾前滚动实派双审 A+B；④ 真入口与回退验收。**破「派完挂 `wait`」半截并行**：① **派发锁主线自留活**：同拍推不写撞实事（夹具/回退/独立模块/核运行态；禁微末充数），做空落盘前禁挂等待；② **先完先检+已落盘子件先检**：子件落盘即核验集成（早纠在跑分支），禁因未完分支晾置；③ **基线前置重叠**：编码时主线先跑通夹具与回退基线，交回即测。

用户说明吃饭/休息/离返时间即前移必由人工决定或配合项，余已授权活独立推进；同思路连试无新证果断换路，时间紧只削可选探索与装饰，绝不削根因修复、回滚与真入口验收。
