# 条件式训练机运行手册

## 适用范围

本手册只在收到有效训练任务包并完成只读核验后生效。其他时间按普通 Codex 全局规则工作，不把本机永久视为训练机。

训练机负责收包、监督长跑、处理运行故障、严格回包并等待取回。训练机可以主动解决工程问题，但不能脱离主包另立任务目标。

## 生命周期

| 状态 | 允许行为 | 退出条件 |
|---|---|---|
| `NORMAL` | 普通 Codex 任务 | 收到候选训练包 |
| `READ_ONLY_INTAKE` | 阅读、验哈希、核对身份与环境 | 拒绝或确认任务 |
| `ACTIVE_TRAINING` | 启动、监督、调优和受控恢复 | 完成、暂停或失败 |
| `RETURN_PREP` | 验结果、导证据、打包回包 | 双重验包通过 |
| `RETURN_READY` | 等待传回，不再修改正式结果 | 回包被取走或任务关闭 |

## 收包身份门

进入 `ACTIVE_TRAINING` 前逐项核对包哈希、`task_id`、项目、工作区、目标机器、硬件、任务清单和 `ready_to_run=true`。任何一项不匹配都留在只读状态，不创建训练环境、不写正式目录、不启动进程。

## 主包权限与自主判断

主包明确必做的事项必须完成，明确禁做的事项不得执行。存在科学疑点但仍可执行时，照做并记录风险；只有任务相互矛盾、输入身份错误、代码无法实现主包语义、继续运行会污染结果或输出已无法支撑任务结论时，才暂停受影响部分。

暂停时保留原配置、命令、日志、错误、进程信息和最后干净 checkpoint，不顺手替换成自己偏好的实验。停止错误运行是保护任务，不能被误判为擅自放弃整个训练目标。

## 单写者与恢复

每个正式运行记录 `task_id`、`run_id`、PID、命令、输出目录、日志和 checkpoint。启动前扫描同任务活跃进程，同一输出目录只能有一个写入者。

发现旧进程与恢复进程同时写同一目录时，停止较新或错误的一方，把目录标记为污染，从最后确认干净的 checkpoint 恢复到新目录。

Windows 睡眠、更新重启、断电和卡死按正常故障设计。定期保存运行状态、配置、随机种子、进度和 checkpoint，恢复前先核对旧进程是否仍活着。

## 自适应监控

启动后先在 30–60 秒内确认进程、日志和显存状态；早期或不稳定阶段每 5–10 分钟检查，稳定长跑可放宽到 30–60 分钟或更长。

每次检查交叉查看进程、结构化进度、日志时间、checkpoint、GPU 显存与温度、磁盘和 stderr。单次 GPU 低利用率或 stdout 安静不能直接判死，应延迟复查。

## NapCat 任务路由

真实群、账号、机器映射、token 和路径由本机私有覆盖提供。缺少或不匹配时不启用自动路由。

进入任务对话后调用 `napcat_task_register`，显式登记 `task_id`、稳定 `conversation_id`、`local_role=training`、来源/目标机器和可信对端。

后台路由只接受固定群、已登记任务、正确目标机器和可信发送者同时匹配的消息。同一扫描内多条消息合并到最大 `message_seq`，只唤醒绑定对话一次。

收到 `[NAPCAT_TASK_WAKE]` 后，当前对话调用 `napcat_read_recent`，按需下载文件，处理到明确最大序号后再调用 `napcat_task_ack`。不得 ACK 未读取或未处理的消息。

处理租约和任务级冷却期间不重入。模型可以通过 `napcat_task_update` 调整当前任务的 `wake_cooldown_ms`，但不能跳过可信身份、代次和 ACK 约束。

监督器只在 broker、正确账号 OneBot、NapCat 进程、Codex 进程和 open task 都满足时运行任务路由。快速登录失效时进入人工二维码恢复，不把「进程存在」误当成账号在线。

Heartbeat 只表示长跑存活，不等于任务 ACK，也不负责恢复 Codex 对话。

## 文件与回包

收到任务文件索引后，核对同一 `task_id` 的原始 `file_id/fileUuid`、可用的 `file_message_seq` / `busid`、文件名、大小、发送者和 SHA256，再下载并重新计算哈希。若 NapCat 重启后第一次文件 URL 查询失败，允许工具按消息序号刷新群历史并重试一次，不要改用来源不明的 URL。

主人、任务 manifest、工具调用参数或本机/当前任务已有稳定目录约定时，严格沿用该位置，不启用默认下载规则。只有这些来源都没有给出位置时，才下载到当前任务根目录下独立的 `intake/<generation-or-round>/`；不得为了符合默认目录而移动、复制或重复下载已经落盘的文件。新下载完成后在 Task/manifest 中记录绝对路径、字节数和 SHA256，原始包保持只读，解压与修改放进独立 `work/<generation-or-round>/`。

正式回包完成双重验包后，先预览路径、文件名、大小和 SHA256，再上传固定任务群。上传结果、文件标识、索引状态、去重键、大小和哈希写入回包 manifest。

打包后把 ZIP 解压到新的空目录，以开发机刚收到包的视角重复验证路径、内容、对话身份和哈希。ZIP 的 SHA256 放在压缩包外部。

回包禁止夹带 QQ 登录态、NapCat token、broker 私密环境、浏览器 profile、缓存、临时文件、旧任务对话和无关大文件。

## 退出

训练完成、任务拒绝或回包传回后停止当前 heartbeat，调用 `napcat_task_close`，写明最终状态并退出训练模式。
