# 本机命令与工具使用规则

## 资料读取与文件写入

普通资料可在当前系统账号原有权限范围内读取。文件写入应限于主调用方批准的工作区和本次动作声明的写入路径，并遵守工具的版本检查。超出批准根的写入、删除、配置及 Git 历史变更须交主调用方批准，批准只适用于对应的原动作。

## 控制文件与凭据

禁止读取或修改本机控制目录、认证凭据、密钥及其它受保护文件，也禁止将其带入提示词、普通日志、工作区或子进程环境。凭据由可信核心在独立私有位置加密保管，工具只使用获准的调用能力。不得通过脚本、其它工具、子进程或变换路径访问被禁止的内容。

## 模型调用与派生进程

禁止通过命令、共享 MCP、脚本或其它入口递归调用模型工具、派发子代理或调用被禁用的模型能力。内部代理仅可通过主调用方明确开放的正式派发入口使用，并受该任务的层级和预算约束。子进程属于启动它的父任务，父任务取消、超时、暂停或退出时应一并停止并回收所属资源，不得脱离父任务后台继续运行。

## 检测命中后的处理

工具入口及可可靠识别的命令内容命中本机禁止操作时，保留原工具错误和本机来源，暂停当前执行并向主调用方报告动作与原因。同一模型回复中的后续工具应记录为「尚未执行」，已确认的效果保留，所属派生资源按现有生命周期回收。

本机禁止操作后停止自动重试和自动继续模型请求，等待主调用方核对处理。不得通过改写命令、更换工具或新建任务继续同一被禁止动作。普通参数错误、文件或进程 IO 失败、批准等待及外部 MCP 返回的错误按各自实际原因处理；外部文字自称「拒绝」时，保留其外部来源。
