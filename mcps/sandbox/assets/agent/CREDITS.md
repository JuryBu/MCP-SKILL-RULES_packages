# Sandbox Agent character assets

These assets reuse the project's approved terminal character artwork and four animation families: resting cat, thinking, inspection, and typing. The maintainer authorized this integration on 2026-10-30. No new character or generated image is introduced by this integration.

The artwork was generated for this project. The character grids and Sixel encodings are project-produced derivatives. No third-party character image pack or terminal library is bundled here. No separate third-party artwork license was supplied with the approved source material.

The original approved appearance is preserved in regular and compact variants. Inspection and typing each use two frames; thinking uses an open-eye and blink pair; the resting cat retains the approved blink and tail frames. Approval, compression, and completion use the same approved human artwork with factual status text.

`manifest.json` records each packaged asset's SHA256 and byte length. Runtime paths are package-relative. Source machine paths, private identifiers, prompts, and conversation records are excluded from this package.
